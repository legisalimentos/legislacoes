Sobre Nós

Conheça a LegisAlimentos

A LegisAlimentos é uma empresa especializada em Engenharia de Alimentos, dedicada a fornecer suporte técnico completo para empresas do setor alimentício. Com uma equipe de profissionais qualificados e registrados no CRQ-RS, oferecemos soluções personalizadas que atendem às necessidades específicas de cada cliente.

Nossa missão é garantir a qualidade e segurança dos produtos alimentícios, auxiliando no desenvolvimento de novos produtos, consultoria especializada e responsabilidade técnica.

Missão, Visão e Valores

Nossos pilares fundamentais

Missão

Fornecer soluções técnicas e consultivas de excelência para o setor alimentício, garantindo a qualidade, segurança e conformidade dos produtos, contribuindo para o crescimento sustentável de nossos clientes e para a saúde dos consumidores.

Visão

Ser reconhecida como referência em engenharia de alimentos e consultoria técnica no Rio Grande do Sul, destacando-se pela qualidade dos serviços, inovação e compromisso com a excelência e a segurança alimentar.

Valores

  • Ética e transparência em todas as relações
  • Compromisso com a qualidade e segurança alimentar
  • Inovação e melhoria contínua
  • Respeito ao cliente e ao consumidor
  • Responsabilidade socioambiental

Nossos Serviços

Soluções completas para sua empresa

Desenvolvimento de Produtos

Desenvolvimento e aprimoramento de produtos alimentícios, desde a formulação até a implementação industrial, garantindo qualidade e conformidade regulatória.

Consultoria

Consultoria técnica especializada para o setor alimentício, auxiliando na otimização de processos, adequação regulatória e melhoria da qualidade.

Responsabilidade Técnica

Assumimos a responsabilidade técnica de sua empresa, garantindo conformidade com as normas e regulamentações do setor alimentício.

Segurança Alimentar

Implementação e gestão de programas de segurança alimentar, incluindo APPCC, BPF e treinamentos para sua equipe.

🗄️ SQL para criar as tabelas:

CREATE TABLE site_settings (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    key TEXT UNIQUE NOT NULL,
    value JSONB NOT NULL,
    updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE site_contents (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    title TEXT NOT NULL,
    description TEXT,
    type TEXT NOT NULL,
    file_url TEXT,
    url TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

ALTER TABLE site_settings ENABLE ROW LEVEL SECURITY;
ALTER TABLE site_contents ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read" ON site_settings FOR SELECT USING (true);
CREATE POLICY "Allow public read" ON site_contents FOR SELECT USING (true);
CREATE POLICY "Allow all write" ON site_settings FOR ALL USING (true);
CREATE POLICY "Allow all write" ON site_contents FOR ALL USING (true);
